# CLI Reference

Every `aro` subcommand and every flag it accepts. Generated by reading
`aro <command> --help` from the release binary — if a flag is missing here, run
that and tell us.

`aro lsp`, `aro mcp`, `aro ask` and `aro kernel` are not registered on Windows
([#701](https://github.com/arolang/aro/issues/701)); `aro build` is compiled out
there ([#613](https://github.com/arolang/aro/issues/613)). Everything else works
on all three platforms.

With no subcommand, `aro <path>` runs. With no arguments and piped stdin, it
evaluates what it is given:

```bash
echo 'Log "Hi" to the <console>.' | aro
```

---

## `aro run` — run an application

```
aro run <path> [<application-arguments> ...]
```

| Flag | Meaning |
|---|---|
| `-e, --entry-point <name>` | Run this feature set instead of `Application-Start` |
| `-v, --verbose` | Verbose logging |
| `--keep-alive` | Keep the process alive (servers) |
| `--debug` | Developer/debug output formatting |
| `--record <file>` | Record events to a JSON file |
| `--replay <file>` | Replay events from a JSON file |
| `--debug-record <file>` | Stream per-statement debug JSONL (Solaro's live view) |

Anything after `<path>` is passed to the application and read with
`Parameters` (ARO-0047).

## `aro build` — compile to a native binary

```
aro build [options] <path>
```

| Flag | Meaning |
|---|---|
| `-o, --output <name>` | Output binary name |
| `--optimize` | Enable optimizations |
| `--size` | Optimize for size rather than speed |
| `--strip` | Strip symbols |
| `--release` | `--optimize --size --strip` |
| `--static` | Statically link the Swift runtime — **the default**; one self-contained file |
| `--dynamic` | Dynamically link it and copy the `.so` files next to the binary (`rpath=$ORIGIN`) |
| `-v, --verbose` | Verbose logging |
| `--keep-intermediate` | Keep `.ll` and `.o` |
| `--emit-llvm` | Emit LLVM IR text instead of a binary |
| `--sign <identity>` | Code-signing identity, or `-` for ad-hoc |
| `--hardened-runtime` | Enable hardened runtime (needed for notarization) |

Needs LLVM 20 and Clang. On Linux, `--static` still leaves Foundation dynamic.

## `aro compile` — parse and report

```
aro compile <path> [-f report|json|ast] [-v]
```

## `aro check` — errors, warnings, body analysis

```
aro check <path> [--warnings|--no-warnings] [--verbose] [--syntax]
```

`--syntax` checks a bare snippet instead of a whole application: a statement, a
block of statements, or a single feature-set body. The argument may be a path,
an inline string, or `-` for stdin. It does not accept a comment before a
feature set, or two feature sets
([#845](https://github.com/arolang/aro/issues/845)).

A green check does **not** yet mean every verb exists
([#844](https://github.com/arolang/aro/issues/844)); it does mean every
qualifier does.

## `aro test` — run colocated tests

```
aro test <path> [-v] [--filter <pattern>] [--no-color] [--record <file>]
```

## `aro diff` — compare feature graphs

```
aro diff <range> [--directory <dir>] [--graph] [--html <file>] [--all]
```

`<range>` is a git revision range (`main..my-branch`) or a single revision, in
which case the working tree is the other side. `--graph` diffs feature sets,
statements and wires rather than lines; `--all` lists untouched feature sets
too.

## `aro repl` — interactive

```
aro repl [-l, --load <file>] [--no-color] [--json]
```

`--json` speaks line-delimited JSON on stdio (ARO-0091) instead of running a
terminal REPL. These three are the only flags; ARO-0049 lists others that were
never implemented.

## `aro kernel` — Jupyter

```
aro kernel [--connection-file <file>]
aro kernel install
```

`install` writes the kernelspec into the user's Jupyter kernels directory; the
front end then launches `aro kernel --connection-file …`. Native ZMQ, no Python
needed.

## `aro debug` — step-debug

```
aro debug [options] [<path>] [<application-arguments> ...]
```

| Flag | Meaning |
|---|---|
| `-e, --entry-point <name>` | Entry point override |
| `--breakpoint <line-or-verb>` | Initial breakpoint; repeatable |
| `--break-condition <LINE=EXPR>` | Pause only when `EXPR` is truthy; repeatable |

## `aro new` — scaffold a plugin

```
aro new plugin <name> --lang swift|rust|c|cpp|python|aro [options]
```

| Flag | Meaning |
|---|---|
| `--name <name>` | Plugin name in kebab-case (alternative to the positional) |
| `--lang <lang>` | **Required**: `swift`, `rust`, `c`, `cpp`, `python`, `aro` |
| `--handle <Handle>` | PascalCase namespace; defaults to one derived from the name |
| `--actions` | Action scaffolding (the default when no other flag is set) |
| `--qualifiers` | Qualifier scaffolding |
| `--services` | Service scaffolding |
| `--system-objects` | System-object scaffolding |
| `--events` | Event-handler scaffolding |
| `--templates` | An `aro-templates` provider |
| `--hybrid` | Both native code and `aro-files` providers |
| `-d, --directory <dir>` | Output directory |

## `aro add` / `aro remove` / `aro plugins`

```
aro add <url> [--ref <tag-or-commit>] [--branch <branch>] [-d <dir>]
aro remove <name> [-d <dir>] [-f]
aro plugins [-d <dir>] [--verbose]
```

`<url>` is a git URL, SSH or HTTPS; `github:org/repo` shorthand works.

## `aro actions` — the live action table

```
aro actions [<name>] [-d <dir>] [--qualifiers] [--format text|json]
```

With a name or verb, explains one action. `--qualifiers` adds the registered
qualifiers. `-d` loads a project's plugins so their actions appear too.

## `aro lsp` / `aro mcp` / `aro ui`

```
aro lsp [--debug] [--stdio]
aro mcp [--base-path <path>] [--verbose]
aro ui [<path>]
```

`aro ui` opens Solaro, which is macOS-only.

## `aro ask` — the local assistant

```
aro ask [<prompt>] [--model <id>] [--yes] [--no-mcp]
        [--temperature <t>] [-v] [--no-think] [--file <path>]
```

Specified in ARO-0092. `--yes` approves every tool call without prompting.
